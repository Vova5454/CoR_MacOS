# CoR_MacOS
CoR but for MacOS


# How to run it:
once you download the game open your terminal. Press command + space and type terminal After that type the 2 following commands:

xattr -d com.apple.quarantine /Users/your_name/Downloads/Cor_MacOS-main/run

chmod +x /Users/your_name/Downloads/CoR_MacOS-main/run

If you see a pop up just click allow.

Instead of writing your_name in the paths write your username on your mac. You know? 

One way to figure out what that name is would be to try to execute the 'run' file in the folder you downloaded. You'll get a message saying that the Author is not trusted or something. Click on the apple icon in your top left corner and then click System Settings. Scroll down to find Privacy & Security and you'll see the run app in the security field which you'll see once you scroll down. Click open anyway, run the run app again, press open anyway, click use password and in the field above the password field you'll see that name.

After that you can just execute the file and there you go.
