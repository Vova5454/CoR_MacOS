# CoR_MacOS
CoR but for MacOS


# How to run it:
once you download the game open your terminal. Press command + space and type terminal After that type the 2 following commands:
xattr -d com.apple.quarantine /Users/your_name/Downloads/Cor_MacOS-main/run
chmod +x /Users/your_name/Downloads/CoR_MacOS-main/run
Instead of writing your_name in the paths write your username on your mac. You know? After that you can just execute the file and there you go.
